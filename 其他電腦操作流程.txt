【重要觀念】
網址:https://math-logic-survey.vercel.app
程式碼:https://github.com/f161717/math-logic-survey (私有)
資料庫:存放在 Turso 雲端(跟著帳號,不在電腦裡)
後台密碼等機密:存在 Vercel 環境變數(跟著帳號,不在電腦裡)

→ 換電腦不會遺失任何東西,只要能上網就能改。


════════════════════════════════════════
方法一:只用瀏覽器改(最簡單,推薦)
════════════════════════════════════════

1. 用瀏覽器開啟 https://github.com/f161717/math-logic-survey
   (用 GitHub 帳號 f161717 登入)

2. 進入想改的檔案,常用檔案:
   - 標題、說明文字 → public/index.html
   - 顏色、字體大小、排版 → public/static/styles.css
   - 按鈕功能、流程邏輯 → public/static/app.js
   - 伺服器設定 → app.py

3. 點右上角鉛筆圖示「Edit this file」(或按鍵盤 . 鍵開啟完整編輯器)

4. 直接修改內容

5. 右上角「Commit changes」→ 藍色按鈕確認存檔

6. 自動觸發部署!約 1 分鐘後 Vercel 自動更新網站,
   不用再做任何事。開 https://math-logic-survey.vercel.app 確認
   (如果看起來沒變,按 Ctrl+F5 強制重新整理)


════════════════════════════════════════
方法二:完整下載到電腦改(要改很多檔案時)
════════════════════════════════════════

事前準備(該電腦只需設定一次):
- 註冊/登入 GitHub 帳號 f161717
- 安裝 git:https://git-scm.com/download/win (下載後一路下一步)
- 安裝 Node.js(內含 npm):https://nodejs.org (選 LTS 版)

操作步驟:
1. 開啟命令提示字元(cmd)或 PowerShell

2. 下載專案(第一次):
   git clone https://github.com/f161717/math-logic-survey.git
   cd math-logic-survey

3. 登入 Vercel(第一次,會開瀏覽器登入 felicia20 帳號):
   npx vercel login
   然後把專案連結到線上的專案:
   npx vercel link
   (選 felicia20 帳號 → math-logic-survey 專案)

4. 修改檔案(用記事本或 VS Code 都可以)

5. 存檔後上傳:
   git add -A
   git commit -m "說明這次改了什麼"
   git push
   (第一次 push 會要求登入 GitHub,照瀏覽器指示即可)

6. push 完 Vercel 自動部署,約 1 分鐘後生效


════════════════════════════════════════
注意事項
════════════════════════════════════════

- GitHub 上「沒有」密碼和資料庫(那是安全的,正常現象)
  後台密碼在 Vercel 網站的 Settings → Environment Variables 查看
  Vercel 後台:https://vercel.com/felicia20/math-logic-survey

- 資料(學生填的回答)都在雲端資料庫,換電腦照常累積,不受影響

- 改壞了想還原:到 GitHub 網頁該檔案的 History,
  找到之前正確的版本 → Restore this commit

- 如果只想看學生填寫狀況、改備註,不用改程式:
  直接開 https://math-logic-survey.vercel.app/admin 登入即可
